# Security Policy

## Supported Versions

The current `main` branch and latest GitHub release receive security fixes.

## Reporting a Vulnerability

Please report vulnerabilities through a private GitHub security advisory when possible.

## Privacy Model

`dev-pulse` is intended to run locally and report local diagnostics. Contributors should avoid:

- remote telemetry
- uploading diagnostic data automatically
- reading secrets from environment variables
- exposing sensitive file paths in reports
